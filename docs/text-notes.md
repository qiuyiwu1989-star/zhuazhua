# 爪爪图文笔记 MVP

中心添加菜单：新建图文笔记、粘贴文字、导入 Markdown/TXT、打开我的笔记。支持把 UTF-8 文本文件或纯文本拖入中心；现有图片导入和悬挂布局保持。设置 → 快捷键可配置新建笔记组合键，默认不占用全局按键。

窗口分为本地笔记列表、Markdown 编辑和原生预览。标题、标签、来源链接可编辑，正文支持基本标题、列表、引用、代码块、粗斜体和分隔线。预览不执行 HTML、不请求远程图片，不是完整 CommonMark 排版引擎（表格、脚注等保留原文）。将图片拖入预览区或使用“插入剪贴板图片”会生成独立本地图片附件和 Markdown 引用。

## 数据和提交边界

- 本地 `Application Support/QiuyiwuCapture/notes.json` 存原文和元数据，文件权限 0600；`note-attachments/` 存 PNG 附件。
- 每次编辑原子落盘；未点“保存并同步”的草稿与新附件只留本机。
- 点击保存并同步才设置 `wantsSync`，使用 attachmentOnly 模式上传图片（保留已有图片备注/OCR等元数据），再 POST `/api/zhuazhua/notes`。使用原有设备凭据，客户端不含 COS 密钥。
- 网络失败保留草稿；手动重试或者启用自动同步时在下次启动重试已提交的笔记。未提交草稿不会自动入档。
- 服务器确认 id 与正整数版本后才标记已入档。本地状态无法写盘时显示错误。
- 版本冲突不覆盖服务器；本地草稿保留，可核对网站版本或复制为新笔记。
- 导入 Markdown 不自动复制相对路径/远程图片，会明确提示重新插入图片。暂不提供云端笔记拉取或双向编辑合并。

## 体验数据

设置 → 常规设置 → 体验改进，默认关闭。开启后向已认证 `/api/zhuazhua/events` 最佳努力发送固定事件名、来源 desktop、结果、耗时、数量、固定错误码。包括笔记入口、导入、同步成功/失败、搜索结果数量；不包含正文、图片、笔记 ID、剪贴板、路径、URL 或搜索词。没有本地遥测队列或重试，不影响保存。

## 验证

`swift test` 使用临时目录、假 token 与 URLProtocol 验证草稿持久化、损坏账本保护、附件本地存储、版本冲突、正确/错误回执、长度和安全预览；不写用户笔记或调用生产上传。运行真实集成测试需另行显式设置 `ZHUA_LIVE_SYNC=1`，本轮未使用。

`APP_OUTPUT=build/ZhuaZhua-notes.app SIGN_IDENTITY=- scripts/build-app.sh debug` 生成独立候选包，避免替换当前运行的 bundle。原默认输出路径不变。
