# 爪爪图标

四枚椭圆爪垫和柔和掌垫，表达轻巧收集。暖橙 #FF6E40，奶油白 #FFF5DE，深墨 #24282B。

- app-icon.svg / app-icon.png：应用图标
- logo.svg：透明底奶油白标志
- mark-dark.svg / mark-light.svg：单色标志
- app-icon.icns：macOS 多尺寸图标
- icon-16.png 至 icon-1024.png：常用 PNG 尺寸

SVG 为可编辑源文件；PNG 与 ICNS 可通过 scripts/make-capture-icon.swift 和构建脚本重建。新增图形采用项目 MIT 许可。
